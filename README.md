## Content and privacy

Only the files in this showcase belong in its public repository. No app binaries, app source, model weights, private reports, credentials or real user files belong here. Screenshots are cropped captures of the disposable macOS guest and use synthetic test files. Mac, NAS and Windows labels are fixture folders, not connected network devices. The original screenshots and test evidence remain private and unchanged.

The logo is an existing project design asset; the screenshots show the current prototype appearance. This is not a production release or a live organizer. There is no analytics, account system, remote font, external script, tracking or file-system access.

## Publishing

This separate public repository hosts only the showcase. GitHub Pages deploys the main branch from its root. The app source repository remains private. Do not copy app source, working directories or private evidence into this repository.
